Liez votre WhatsApp en moins d'une minute

Entrez votre numéro, recevez un code à 8 caractères et saisissez-le dans WhatsApp. Votre Session ID arrive ensuite dans vos messages : c'est lui qui connecte le bot à votre compte.

  1. Entrez votre numéro avec l'indicatif du pays, puis demandez le code.
  2. Saisissez le code dans WhatsApp : Paramètres, Appareils connectés, Connecter un appareil, puis « Connecter avec le numéro de téléphone ».
  3. Collez le Session ID dans la variable SESSION_ID de votre hébergeur (Katabump, Bot-Hosting...) et démarrez le bot.
